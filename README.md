# 🧩 Task Tracker — Frontend (React)

This is the **React-powered frontend** of the Task Tracker App.  
Built with **Vite**, styled using **Tailwind CSS**, and connected to the backend API hosted on Render.

---

## ✨ Features

- Add/Edit/Delete tasks
- Mark tasks as completed
- Filter by priority, status, and due dates
- Light/Dark mode with animation
- Token-based protected routes
- Responsive UI for mobile & desktop

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- Axios
- Lucide-react
- JWT Authentication
- Vercel Deployment
